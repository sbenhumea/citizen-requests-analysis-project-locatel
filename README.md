# Applied AI Diploma Final Project: Mexico City Citizen Requests Analysis

This project aimed to develop a model capable of predicting the resolution time of citizen requests in Mexico City submitted through the SUAC (Unified Citizen Services System). To this end, two modeling approaches were developed: one based on regression and the other on classification. In the regression branch, resolution time was predicted as a continuous variable using Linear Regression and a Random Forest Regressor. On the classification side, the goal was to predict the time-range class into which a request would fall, using models such as Decision Trees and a Random Forest Classifier. In both cases, the predictive results were not satisfactory enough for the models to be used as complementary tools that inform citizens about the estimated resolution time of their requests; however, interesting findings emerged regarding request behavior and how requests are recorded. It was concluded that additional data complementing the original dataset is needed to improve the models' predictive performance. Finally, in addition to collecting more variables, it was proposed to use more robust training configurations and to share and implement the findings within citizen service units in order to improve current methodologies, refine existing processes, and address areas for improvement.
